# PT-06 — Classes de palavras

## Resumo

São **10 classes**: substantivo, adjetivo, artigo, numeral, pronome, verbo (**variáveis**); advérbio, preposição, conjunção, interjeição (**invariáveis**). Fora delas, as **palavras denotativas** (só, apenas, inclusive, até, sequer, eis).

| Classe | Função | Exemplos |
|---|---|---|
| **Substantivo** | nomeia | bombeiro, coragem, Maceió |
| **Adjetivo** | caracteriza o substantivo | corajoso; locução: "de mãe" = materno |
| **Artigo** | determina (o, a) ou indetermina (um, uma) | trocar um pelo outro muda o sentido |
| **Numeral** | quantidade/ordem | dois (cardinal), segundo (ordinal), dobro, metade |
| **Pronome** | substitui ou acompanha o nome | ele, o, lhe, este, meu, alguém, que, cujo |
| **Verbo** | ação, estado, fenômeno | correr, ser, chover |
| **Advérbio** | modifica verbo, adjetivo ou advérbio | rapidamente, bem, muito, não, quase |
| **Preposição** | liga termos | a, de, em, para, com, entre |
| **Conjunção** | liga orações ou termos | e, mas, porque, embora, que, se |
| **Interjeição** | emoção | ufa!, socorro! |

## Teoria

### Pronomes que caem
- **o, a, os, as** = **objeto direto** ("Encontrei-**o**"). **lhe, lhes** = **objeto indireto** ("Obedeço-**lhe**"). "Eu **lhe** vi" está errado (ver é VTD → "eu o vi").
- **cujo:** posse; concorda com o possuído; **sem artigo depois** ("o autor **cujo livro**"; nunca "cujo o").
- **onde:** só para **lugar físico**; para situação, época etc., use "em que", "na qual".
- **para mim × para eu:** antes de infinitivo de que o pronome é sujeito → "para **eu** ler". Após preposição, sem verbo → "entre **mim** e ele", "para **mim**".

### O "SE"
| Função | Quando | Exemplo |
|---|---|---|
| **Partícula apassivadora** | VTD (ou VTDI) + se → **verbo concorda** com o sujeito | "Vendem-se casas"; "Solicita-se **que confirmem**" (sujeito oracional) |
| **Índice de indeterminação do sujeito** | VTI, VI ou VL + se → **singular** | "Precisa-se **de** voluntários"; "Investe-se **na** prevenção"; "Vive-se bem" |
| **Pronome reflexivo** | ação sobre si | "Feriu-se" |
| **Conjunção condicional** | = caso | "**Se** chover, adia" |
| **Conjunção integrante** | inicia oração substantiva | "Não sei **se** virá" |

### O "QUE"
Pronome relativo ("o relatório **que** entreguei" = o qual) · conjunção integrante ("Sei **que** virá") · conjunção causal, comparativa, consecutiva · preposição ("tenho **que** sair" = de) · advérbio de intensidade ("**Que** coragem!") · partícula de realce · substantivo ("um **quê** de mistério").

### Invariáveis e variáveis traiçoeiros
- **Invariáveis:** **menos** (nunca "menas"), **alerta**, pseudo, **meio** = um pouco ("meio cansada").
- **Variáveis:** **anexo, incluso, obrigado, mesmo, próprio, quite, bastante** (adjetivo): "seguem **anexas**", "elas **mesmas**", "**bastantes** viaturas". **Meia** = metade ("meia hora").

## Manias da banca

- **"Se" apassivador × indeterminador** (ligado à concordância: "Precisa-se de", "Vendem-se").
- **"Que" relativo × integrante.**
- **"Lhe" como objeto direto** ("eu lhe vi").
- **"Cujo o", "onde" para situação, "para mim fazer".**
- **Classe trocada** (advérbio chamado de adjetivo; ordinal chamado de cardinal).
- **Menos/alerta variando; anexo/mesmo sem variar.**
