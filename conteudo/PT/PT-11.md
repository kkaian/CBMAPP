# PT-11 — Regência verbal e nominal

## Resumo

**Regência:** relação entre o termo **regente** (verbo ou nome) e o **complemento**, incluindo a **preposição** exigida. Muita questão de **crase** é, no fundo, de regência.

| Verbo | Sentido | Regência | Exemplo |
|---|---|---|---|
| **assistir** | ver, presenciar | **a** | assisti **ao** filme / **à** palestra |
| | prestar assistência | direto | o médico assistiu **o** paciente |
| **aspirar** | desejar | **a** | aspira **ao** cargo |
| | inalar | direto | aspirou **a** fumaça (artigo) |
| **visar** | almejar | **a** (tradicional) | visa **à** aprovação |
| | mirar, dar visto | direto | visou **o** alvo |
| **obedecer / desobedecer** | — | **a** | obedeça **aos** protocolos |
| **preferir** | — | A **a** B (nunca "do que", "mais") | prefiro estudar **a** dormir |
| **chegar / ir / voltar** | movimento | **a** (não "em") | chegou **ao** local |
| **implicar** | acarretar | direto (não "em") | implica riscos |
| **esquecer / lembrar** | sem pronome | direto | esqueci **o** horário |
| **esquecer-se / lembrar-se** | pronominal | **de** | esqueci-**me do** horário |
| **namorar** | — | direto | namora **a** moça |
| **querer** | desejar / estimar | direto / **a** | quero um café / quero bem **aos** amigos |
| **pagar / perdoar** | coisa = direto; pessoa = indireto | | pagou **a conta ao** fornecedor |
| **informar, avisar, certificar** | algo **a** alguém **ou** alguém **de** algo | | informou **aos bombeiros que…**; informou-**os da** mudança |
| **proceder** | dar início | **a** | procedeu-se **à** vistoria |
| **custar** | ser difícil | coisa é sujeito (tradicional) | custou **ao** sargento entender |
| **simpatizar** | — | **com**, não pronominal | simpatizo com ele |
| **morar, residir** | — | **em** | a rua **em que** moro |

## Teoria

### Regência e pronome relativo
A preposição exigida pelo verbo vai **antes do relativo**: "o cargo **a que** aspiro", "o equipamento **de que** necessito", "a ordem **a que** obedeci", "a rua **em que** moro".

### Regência nominal (nomes que pedem preposição)
acesso **a** · apto **a/para** · favorável **a** · contrário **a** · respeito **a/por** · ojeriza **a/por** · capacidade **de/para** · certeza **de** · dúvida **sobre/em** · preferência **por** · atentado **a/contra** · obediência **a** · alheio **a**.

### Preposição exigida × preposição com sentido próprio
Em "contribui **para** a proteção", o "para" é **exigido pelo verbo** (regência), e não introduz finalidade.

## Manias da banca

- **"Assisti o filme"** → assisti ao filme.
- **"Prefiro X do que Y"** → prefiro X a Y.
- **"Chegou no local"** → chegou ao local.
- **"Implicou em"** (acarretar) → implicou.
- **"Obedecer os"** → obedecer aos.
- **Pronome relativo sem a preposição** ("a ordem que obedeci").
