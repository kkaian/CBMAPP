# PT-11 — Regência verbal e nominal

## Resumo

**Regência:** relação entre o termo **regente** (verbo ou nome) e o **complemento**, incluindo a **preposição** exigida. Muita questão de **crase** é, no fundo, de regência.

| Verbo | Sentido | Regência | Exemplo |
|---|---|---|---|
| **assistir** | ver, presenciar | **a** | assisti **ao** filme / **à** palestra |
| | prestar assistência | direto | o médico assistiu **o** paciente |
| **aspirar** | desejar | **a** | aspira **ao** cargo |
| | inalar | direto | aspirou **a** fumaça (artigo) |
| **visar** | almejar | **a** (tradicional) | visa **à** aprovação |
| | mirar, dar visto | direto | visou **o** alvo |
| **obedecer / desobedecer** | — | **a** | obedeça **aos** protocolos |
| **preferir** | — | A **a** B (nunca "do que", "mais") | prefiro estudar **a** dormir |
| **chegar / ir / voltar** | movimento | **a** (não "em") | chegou **ao** local |
| **implicar** | acarretar | direto (não "em") | implica riscos |
| **esquecer / lembrar** | sem pronome | direto | esqueci **o** horário |
| **esquecer-se / lembrar-se** | pronominal | **de** | esqueci-**me do** horário |
| **namorar** | — | direto | namora **a** moça |
| **querer** | desejar / estimar | direto / **a** | quero um café / quero bem **aos** amigos |
| **pagar / perdoar** | coisa = direto; pessoa = indireto | | pagou **a conta ao** fornecedor |
| **informar, avisar, certificar** | algo **a** alguém **ou** alguém **de** algo | | informou **aos bombeiros que…**; informou-**os da** mudança |
| **proceder** | dar início | **a** | procedeu-se **à** vistoria |
| **custar** | ser difícil | coisa é sujeito (tradicional) | custou **ao** sargento entender |
| **simpatizar** | — | **com**, não pronominal | simpatizo com ele |
| **morar, residir** | — | **em** | a rua **em que** moro |

## Teoria

### 1. O que é regência
**Regência** é a relação de **dependência** entre um termo **regente** (verbo ou nome) e o termo **regido** (seu complemento), incluindo a **preposição** que o regente exige.
- **Regência verbal:** o regente é um **verbo**: "**obedecer ao** regulamento".
- **Regência nominal:** o regente é um **nome** (substantivo, adjetivo, advérbio): "**obediência ao** regulamento", "**favorável à** proposta".

**Por que importa tanto:** muitas questões de **crase** (PT-12), de **pronome relativo** ("o cargo **a que** aspiro") e de **reescrita** (trocar um verbo por um sinônimo de regência diferente) dependem dela.

**Mudar a regência pode mudar o sentido:** "**assistir o** paciente" (ajudar) × "**assistir ao** jogo" (ver).

### 2. Verbos que mudam de sentido conforme a regência
| Verbo | Regência | Sentido | Exemplo |
|---|---|---|---|
| **assistir** | **VTI (a)** | **ver**, presenciar | "Assisti **ao** treinamento." "Assisti **à** palestra." (não admite "lhe": "assisti **a ele**") |
| | VTD | prestar **assistência**, ajudar | "O socorrista assistiu **a** vítima." "Assistiu-**a**." |
| | VTI (a) | caber, pertencer (direito) | "Esse direito assiste **ao** servidor." |
| | VI (em) | morar | "Assiste **em** Maceió." (pouco usado) |
| **aspirar** | **VTI (a)** | **desejar**, pretender | "Aspira **ao** posto de sargento." |
| | VTD | **inalar**, sorver | "Aspirou **a** fumaça." (artigo, não preposição) |
| **visar** | **VTI (a)** | **almejar**, ter como objetivo | "O treinamento visa **à** eficiência." (a gramática tradicional exige o "a"; gramáticos e dicionários modernos já admitem o uso direto, sobretudo antes de infinitivo: "visa melhorar". Na dúvida, a forma com "a" é a mais segura) |
| | VTD | **mirar**; dar **visto** | "Visou **o** alvo." "O gerente visou **o** cheque." |
| **querer** | VTD | **desejar** | "Quero **um** café." |
| | VTI (a) | **estimar**, gostar | "Quero bem **aos** meus soldados." |
| **proceder** | VI | ter fundamento; vir de | "A reclamação **procede**." "O voo procede **de** Recife." |
| | VTI (a) | **dar início**, realizar | "Procedeu-se **à** vistoria." |
| **implicar** | VTD | **acarretar**, ter como consequência | "A falha **implica** riscos." (não "implica **em**") |
| | VTDI | envolver alguém | "Implicaram-**no** **no** crime." |
| | VTI (com) | antipatizar | "Implicava **com** o colega." |
| **custar** | VTI (sentido de **ser difícil**) | a coisa difícil é o **sujeito**; a pessoa, objeto indireto | "Custou-**me** entender." "Custou **ao** sargento aceitar." (evite "o sargento custou a aceitar" na norma culta tradicional) |
| **agradar** | VTI (a) | **satisfazer** | "A decisão agradou **à** tropa." |
| | VTD | **acariciar** | "Agradou **o** cão." |
| **chamar** | VTD | **convocar** | "Chamou **os** voluntários." |
| | VTD ou VTI + predicativo | **qualificar** | "Chamaram-**no** (ou **lhe**) **de** herói." / "Chamaram-no herói." |

### 3. Verbos com regência que a norma culta cobra
| Verbo | Regência correta | Erro comum |
|---|---|---|
| **obedecer / desobedecer** | **a**: "Obedeça **aos** protocolos." "Obedeço-**lhe**." | "obedecer **os** protocolos" |
| **preferir** | **algo A algo**: "Prefiro estudar **a** dormir." "Prefiro o mar **à** montanha." | "prefiro **mais**…", "prefiro… **do que**…" |
| **chegar, ir, voltar, retornar, dirigir-se** (movimento) | **a**: "Chegou **ao** local." "Vou **à** base." | "chegou **no** local" (coloquial) |
| **morar, residir, situar-se, estar** (lugar fixo) | **em**: "Mora **na** rua X." "a rua **em que** moro" | — |
| **esquecer, lembrar** (sem pronome) | **VTD**: "Esqueci **o** horário." | — |
| **esquecer-se, lembrar-se** (pronominal) | **de**: "Esqueci-**me do** horário." "Lembrou-**se de** que havia vítimas." | "esqueci **do** horário" (sem o pronome, coloquial) |
| **namorar** | **VTD**: "Namora **a** moça." | "namora **com**" |
| **simpatizar, antipatizar** | **com**, e **não** são pronominais | "**se** simpatizo" |
| **pagar, perdoar** | **coisa** = objeto **direto**; **pessoa** = objeto **indireto** | "Pagou **a conta** (OD) **ao fornecedor** (OI)." "Perdoou **ao** filho." |
| **informar, avisar, comunicar, certificar, notificar, prevenir** | **algo a alguém** **ou** **alguém de algo** | "Informou **a** decisão **aos** bombeiros." / "Informou **os** bombeiros **da** decisão." (nunca os dois objetos sem preposição) |
| **atender** | VTD ou VTI (a), conforme o caso | "Atendeu **o** telefone / **ao** telefone"; "atender **aos** requisitos" |
| **responder** | VTI (a) quando há destinatário | "Respondeu **ao** ofício." |
| **ansiar, aspirar, visar** (desejo) | **a** ou **por** | "Anseia **por** justiça." |
| **reparar** | VTD (consertar) / VTI (a, em: notar) | "Reparou **a** viatura." "Reparou **no** detalhe." |
| **pisar** | **VTD** | "Não pise **a** grama." (coloquial: "na grama") |
| **ir, chegar a pé, a cavalo** | preposição a | "Foi **a pé**." |

### 4. Regência nominal
| Nome | Preposição | Exemplo |
|---|---|---|
| **acesso** | a | "acesso **ao** prédio" |
| **apto** | a, para | "apto **ao** serviço", "apto **para** o cargo" |
| **favorável / contrário** | a | "favorável **à** mudança" |
| **obediência** | a | "obediência **às** normas" |
| **respeito** | a, por, com, para com | "respeito **aos** mais velhos", "respeito **pela** vida" |
| **capacidade** | de, para | "capacidade **de** liderar" |
| **certeza, convicção** | de | "certeza **de** que virá" |
| **dúvida** | sobre, acerca de, em | "dúvida **sobre** o horário" |
| **preferência** | por | "preferência **por** voluntários" |
| **atentado** | a, contra | "atentado **contra** a vida" |
| **alheio** | a | "alheio **ao** perigo" |
| **ansioso** | de, para, por | "ansioso **pelo** resultado" |
| **imune** | a, de | "imune **a** críticas" |
| **compatível, conforme** | com | "compatível **com** o cargo" |
| **necessário, essencial, indispensável, útil, prejudicial** | a, para | "essencial **à** segurança" |
| **junto** | a, de | "junto **à** comunidade" |
| **residente, situado, morador** | em | "residente **em** Arapiraca" |
| **próximo** | a, de | "próximo **ao** quartel" |
| **combate** | a | "combate **ao** incêndio" |

### 5. Regência e pronome relativo (onde a banca mais pega)
A preposição exigida pelo verbo (ou nome) **da oração adjetiva** vem **antes** do pronome relativo. **Método:** reconstrua a frase com o antecedente no lugar do relativo.
| Frase | Reconstrução | Correto |
|---|---|---|
| "O cargo ___ aspiro." | aspiro **ao** cargo | "o cargo **a que** aspiro" (ou **ao qual**) |
| "O equipamento ___ necessito." | necessito **do** equipamento | "o equipamento **de que** necessito" (ou **do qual**) |
| "A ordem ___ obedeci." | obedeci **à** ordem | "a ordem **a que** obedeci" (ou **à qual**) |
| "A rua ___ moro." | moro **na** rua | "a rua **em que** moro" (ou **onde**, **na qual**) |
| "O plano ___ falei." | falei **do** plano | "o plano **de que** falei" |
| "O filme ___ assisti." | assisti **ao** filme | "o filme **a que** assisti" (ou **ao qual**) |
| "A vítima ___ socorremos." | socorremos **a** vítima (VTD) | "a vítima **que** socorremos" (sem preposição) |
| "As pessoas ___ confio." | confio **nas** pessoas | "as pessoas **em quem** confio" (ou **nas quais**) |

Omitir a preposição ("o equipamento **que** necessito", "o filme **que** assisti") é erro na norma culta e é item clássico de prova.

### 6. Preposição exigida × preposição com sentido próprio
- Em "contribui **para** a proteção", o "para" é **exigido pelo verbo** (contribuir para): é **regência**, sem valor de finalidade.
- Em "estudou **para** passar", o "para" introduz **finalidade** (adjunto adverbial).
- Em "acesso **ao** prédio", o "a" é regência nominal; em "chegou **à** noite", é parte de locução adverbial de tempo.

### 7. Regência na reescrita
Ao trocar um verbo por sinônimo, confira se a **regência** é a mesma:
- "**Necessita de** apoio" → "**Precisa de** apoio" (mantém) → "**Requer** apoio" (VTD: tira o "de") → "~~**Carece** apoio~~" (errado: carecer **de**).
- "**Assistiu ao** treinamento" → "**Viu o** treinamento" (VTD: tira o "a").
- "**Obedecer às** normas" → "**Cumprir as** normas" (VTD: sem crase).
- "**Lembrou** o compromisso" → "**Lembrou-se do** compromisso" (com pronome, ganha "de").

### 8. Bizus finais
- **Assistir a** = ver; **assistir** (direto) = ajudar.
- **Aspirar a** = desejar; aspirar (direto) = inalar. **Visar a** = almejar.
- **Implicar** = acarretar: **direto** (sem "em").
- **Preferir A a B** (sem "mais", sem "do que").
- **Obedecer a**; **chegar a**; **morar em**.
- **Esquecer** (direto) × **esquecer-se de**.
- Informar **algo a alguém** ou **alguém de algo**.
- Preposição do verbo vai **antes do relativo**: "o equipamento **de que** necessito"; "o filme **a que** assisti".
- Trocar verbo por sinônimo exige conferir a **regência**.

## Manias da banca

- **"Assisti o filme"** → assisti ao filme.
- **"Prefiro X do que Y"** → prefiro X a Y.
- **"Chegou no local"** → chegou ao local.
- **"Implicou em"** (acarretar) → implicou.
- **"Obedecer os"** → obedecer aos.
- **Pronome relativo sem a preposição** ("a ordem que obedeci").
