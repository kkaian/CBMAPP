# ING-02 — Vocabulário, cognatos e falsos cognatos

## Resumo

- **Cognatos verdadeiros:** palavras parecidas com o português e de mesmo sentido (emergency, rescue, danger, evacuate, temperature).
- **Falsos cognatos (false friends):** parecem, mas significam outra coisa. A pegadinha clássica.

| Inglês | Parece… | Mas significa |
|---|---|---|
| **actually** | atualmente | **na verdade, de fato** |
| **eventually** | eventualmente | **por fim, finalmente** |
| **library** | livraria | **biblioteca** (livraria = bookstore) |
| **pretend** | pretender | **fingir** (pretender = intend) |
| **realize** | realizar | **perceber, dar-se conta** |
| **parents** | parentes | **pais** (parentes = relatives) |
| **push** / **pull** | puxar / — | **empurrar** / **puxar** |
| **fabric** | fábrica | **tecido** (fábrica = factory) |
| **college** | colégio | **faculdade** |
| **sensible** | sensível | **sensato** (sensível = sensitive) |
| **exit** | êxito | **saída** (êxito = success) |
| **attend** | atender | **comparecer** |
| **deceive** | decepcionar | **enganar** (decepcionar = disappoint) |
| **costume** | costume | **fantasia** (costume = custom) |
| **comprehensive** | compreensivo | **abrangente** |
| **lecture** | leitura | **palestra** |
| **prejudice** | prejuízo | **preconceito** |
| **injury** | injúria | **ferimento, lesão** |
| **data** | data | **dados** (data = date) |
| **novel** | novela | **romance** (livro) |
| **exquisite** | esquisito | **requintado** |
| **support** | suportar | **apoiar** |

## Teoria

### Vocabulário de emergência
fire hose (mangueira) · ladder (escada de mão) · smoke (fumaça) · flames (chamas) · wildfire (incêndio florestal) · flood (enchente) · drought (seca) · landslide (deslizamento) · rescue (resgate) · first aid (primeiros socorros) · cardiac arrest (parada cardíaca) · chest compressions (compressões torácicas) · choking (engasgo) · burn (queimadura) · casualties (vítimas) · injured (ferido) · trapped (preso, encurralado) · rip current (corrente de retorno) · lifeguard (salva-vidas) · warning (aviso) · shelter (abrigo) · blanket (cobertor).

### Formação de palavras
- **un-, in-, im-, dis-** = negação: unsafe, unlikely, impossible, disagree.
- **-less** = sem (careless, helpless); **-ful** = com (careful, helpful).
- **-er/-or** = agente (firefighter, operator); **-tion** = substantivo (prevention, detection).
- **re-** = de novo (rebuild, replant).

### Phrasal verbs comuns
put out (apagar) · give up (desistir) · look for (procurar) · look after (cuidar de) · keep up (acompanhar) · fall behind (ficar para trás) · run out (acabar) · turn into (transformar-se em) · rely on (confiar em) · run away (fugir).

### Sentido pelo contexto
A banca pergunta o sentido **naquele texto**. Teste a substituição: se a frase continua com o mesmo sentido, o item está CERTO ("witnessed" → "saw"; "turning into" → "becoming"). Se a substituta é **antônimo**, está ERRADO ("tough" → "fragile"; "keep up" → "fall behind").

## Manias da banca

- **actually, eventually, library, pretend, realize, parents** (os campeões).
- **Substituição por antônimo** apresentada como sinônimo.
- **Phrasal verb** com sentido trocado.
- **Prefixos/sufixos** com valor invertido (-less como "com").
