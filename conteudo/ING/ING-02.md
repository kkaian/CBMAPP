# ING-02 — Vocabulário, cognatos e falsos cognatos

## Teoria

### 1. Cognatos: o atalho para ler sem saber todas as palavras
**Cognatos verdadeiros** são palavras de **origem comum** (muitas vêm do latim), com forma e sentido parecidos em inglês e português. Num texto técnico, eles podem ser **metade** do vocabulário:
- *emergency, rescue* (resgate), *danger, evacuate, temperature, population, government, structure, important, necessary, information, community, prevention, ambulance, hospital, victim, risk, climate, oxygen, carbon, effect, cause, region, process, system*.

**Terminações que se correspondem:**
| Inglês | Português | Exemplos |
|---|---|---|
| **-tion** | **-ção** | *prevention* (prevenção), *evacuation*, *detection*, *population* |
| **-ty** | **-dade** | *city* (cidade), *capacity*, *security*, *humidity* |
| **-ly** | **-mente** | *rapidly* (rapidamente), *finally*, *naturally* |
| **-ous** | **-oso** | *dangerous* (perigoso), *famous*, *numerous* |
| **-al** | **-al** | *national, natural, general* |
| **-ic, -ical** | **-ico** | *economic, chemical, electric* |
| **-ist** | **-ista** | *scientist*, *specialist* |
| **-ize** | **-izar** | *organize*, *mobilize* |

### 2. Falsos cognatos (false friends)

|---|---|---|---|

| **library** | livraria | **biblioteca** | *bookstore* |

| **costume** | costume | **fantasia, traje** | *custom, habit* |
| **comprehensive** | compreensivo | **abrangente, completo** | *understanding* |

**Atenção a *casualties*:** em textos de desastres, aparece muito com o sentido de **vítimas** ("*the earthquake caused hundreds of casualties*").

### 4. Formação de palavras (descobrir o sentido pelas partes)
| Afixo | Sentido | Exemplos |
|---|---|---|
| **un-, in-, im-, il-, ir-, dis-, non-** | **negação**, contrário | *unsafe* (inseguro), *unlikely* (improvável), *impossible*, *illegal*, *irregular*, *disagree*, *non-toxic* |
| **mis-** | errado, mal | *misunderstand* (entender mal), *misuse* |
| **re-** | de novo | *rebuild* (reconstruir), *replant* |
| **pre-** / **post-** | antes / depois | *prevent*, *post-war* |
| **over-** / **under-** | excesso / falta | *overheat* (superaquecer), *underestimate* (subestimar) |
| **-less** | **sem** | *careless* (descuidado), *helpless* (indefeso), *homeless* (sem-teto) |
| **-ful** | **com**, cheio de | *careful* (cuidadoso), *helpful*, *harmful* (prejudicial) |
| **-er, -or, -ist** | **agente** (quem faz) | *firefighter*, *operator*, *scientist* |
| **-tion, -ment, -ness, -ity** | **substantivo** | *prevention*, *development*, *awareness* (consciência), *ability* |
| **-able, -ible** | que pode ser | *flammable* (inflamável), *visible*, *avoidable* (evitável) |
| **-ize, -en** | tornar | *modernize*, *strengthen* (fortalecer), *widen* |
| **-ly** | advérbio de modo | *quickly*, *safely* |

**Atenção:** *inflammable* e *flammable* significam a **mesma coisa** (inflamável); o contrário é **non-flammable**. O "in-" aqui **não** é negação.

**Palavras compostas:** leia **de trás para a frente**: *fire station* = estação de fogo (**quartel** de bombeiros); *smoke detector* = detector de fumaça; *water supply* = abastecimento de água; *emergency exit* = saída de emergência.

### 6. Sentido pelo contexto e substituição
A banca pergunta o sentido da palavra **naquele texto**. Método:
1. Leia a **frase inteira** (e a anterior).
2. Descubra a **classe** da palavra (verbo, substantivo, adjetivo).
3. **Substitua** pela opção do item e veja se a frase mantém o sentido.

| Substituição | Veredito |
|---|---|
| *witnessed* → *saw* | ✔ (presenciou = viu) |
| *turning into* → *becoming* | ✔ |
| *crucial* → *essential* | ✔ |
| *tough* → *fragile* | ✘ (antônimos) |
| *keep up* → *fall behind* | ✘ (antônimos) |
| *actually* → *currently* | ✘ (falso cognato) |
| *eventually* → *finally* | ✔ |
| *however* → *therefore* | ✘ (contraste × conclusão) |

**Polissemia:** a mesma palavra muda de sentido conforme o contexto: *fire* (fogo; demitir; disparar), *run* (correr; administrar: *run a company*), *issue* (questão; emitir), *matter* (assunto; importar: *it matters*), *spring* (primavera; nascente; mola).

### 7. Bizus finais
- Cognatos ajudam: **-tion = -ção**, **-ty = -dade**, **-ly = -mente**, **-ous = -oso**.
- Falsos amigos campeões: **actually** (na verdade), **eventually** (por fim), **pretend** (fingir), **realize** (perceber), **library** (biblioteca), **parents** (pais), **push** (empurrar), **casualty** (vítima), **injury** (lesão), **prejudice** (preconceito), **expert** (especialista), **policy** (política).
- **-less** = sem; **-ful** = com; **un-/dis-/in-** = negação (exceto *inflammable* = inflamável).
- Compostos: leia **de trás para a frente** (*fire station* = quartel).
- **put out** = apagar; **break out** = irromper; **carry out** = realizar.
- Teste a substituição **no contexto**.

## Manias da banca

- **actually, eventually, library, pretend, realize, parents** (os campeões).
- **Substituição por antônimo** apresentada como sinônimo.
- **Phrasal verb** com sentido trocado.
- **Prefixos/sufixos** com valor invertido (-less como "com").
