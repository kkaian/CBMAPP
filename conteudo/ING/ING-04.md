# ING-04 — Conectivos e referência pronominal

## Resumo

### Conectivos por grupo de sentido
| Relação | Conectivos |
|---|---|
| **Contraste / concessão** | **however, but, yet, still, although, though, even though, nevertheless, whereas, while, despite / in spite of** (+ nome), on the other hand |
| **Adição** | **and, moreover, furthermore, in addition, besides, also** |
| **Causa** | **because, since, as, due to, owing to** |
| **Resultado / conclusão** | **therefore, thus, hence, so, consequently, as a result, for this reason** |
| **Exemplo** | **for example, for instance, such as** |
| **Reformulação** | **in other words, that is** |
| **Condição** | **if, unless** (= if not), provided that |
| **Finalidade** | **to, in order to, so that** |
| **Alternativa** | **instead (of)** (em vez de), or |

**Cuidado:** "still" e "yet" podem ser advérbios de tempo ("still" = ainda), mas no início de oração costumam marcar **contraste** ("Still, technology has its limits"). "While" pode indicar tempo ou contraste.

### Referência
| Tipo | Formas |
|---|---|
| Pronomes sujeito / objeto | I–me, you–you, he–him, she–her, it–it, we–**us**, they–**them** |
| Possessivos | my, your, his, her, its, our, **their** |
| Reflexivos | myself, herself, **themselves** (retomam o próprio sujeito) |
| Demonstrativos | **this/these** (perto; o que vai ser dito), **that/those** (longe; o que já foi dito) |
| Relativos | **who** (pessoas), **which** (coisas, animais), **that** (ambos), **whose** (posse = cujo), where |

## Teoria

### Como resolver item de referência
1. Ache o pronome no texto.
2. Veja **número e gênero** (it = singular; they/their = plural; her = feminino).
3. Teste a substituição pelo candidato a referente: o sentido se mantém?

Exemplos (2021): "some portions of the tropical landscape already may release more carbon than **they** store" → they = some portions; "**the tropical landscape**" = the Amazon rainforest.

"**This**" pode retomar uma ideia inteira: "Software shows where every unit is. **This** allows operators to send the closest unit."

### Orações relativas
- **Defining** (sem vírgulas): identifica de quem se fala ("The officer **whose team won** was promoted").
- **Non-defining** (entre vírgulas): informação extra sobre todos ("Firefighters, **whose work is dangerous**, must train").

## Manias da banca

- **Grupo do conectivo trocado** (however como adição; therefore como contraste; in other words como contradição).
- **Referente trocado** (their → "homes"; themselves → "others"; it → plural).
- **Who × which** invertidos.
- **Still/yet** lidos só como "ainda" quando marcam contraste.
