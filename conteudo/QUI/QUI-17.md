# QUI-17 — Nomenclatura IUPAC (1 a 8 carbonos)

## Resumo

**Nome = prefixo (nº de C da cadeia principal) + infixo (ligações) + sufixo (função)**

| Prefixo | C | | Infixo | Ligações | | Sufixo | Função |
|---|---|---|---|---|---|---|---|
| met- | 1 | | **-an-** | só simples | | **-o** | hidrocarboneto |
| et- | 2 | | **-en-** | 1 dupla | | **-ol** | álcool |
| prop- | 3 | | **-in-** | 1 tripla | | **-al** | aldeído |
| but- | 4 | | -dien- | 2 duplas | | **-ona** | cetona |
| pent- | 5 | | | | | ácido **…-oico** | ácido carboxílico |
| hex- | 6 | | | | | **-amina** | amina |
| hept- | 7 | | | | | **-amida** | amida |
| oct- | 8 | | | | | | |

**Ramificações (grupos substituintes):** metil (–CH₃), etil (–CH₂CH₃), propil, isopropil (–CH(CH₃)₂).

**Regras básicas:**
1. **Cadeia principal:** a mais longa que contenha o grupo funcional e as insaturações.
2. **Numeração:** começa pela extremidade mais próxima do **grupo funcional**; depois, da **insaturação**; depois, das **ramificações** (menores números).
3. **Localizadores** indicam posições (but-**1**-eno, propan-**2**-ol); **di-, tri-** para grupos repetidos (2,2-dimetil...).
4. Ramificações em **ordem alfabética**, antes do nome da cadeia (3-etil-2-metil...).

## Teoria

### Exemplos resolvidos
| Estrutura | Nome IUPAC | Nome usual |
|---|---|---|
| CH₄ | metano | gás natural |
| CH₃–CH₃ | etano | |
| CH₂=CH₂ | eteno | etileno |
| HC≡CH | etino | acetileno |
| CH₂=CH–CH₂–CH₃ | but-1-eno | |
| CH₃–CH=CH–CH₃ | but-2-eno | |
| CH₃–CH(CH₃)–CH₃ | metilpropano | isobutano |
| C(CH₃)₄ | dimetilpropano (2,2-dimetilpropano) | neopentano |
| CH₃–CH(CH₃)–CH₂–CH₃ | 2-metilbutano | isopentano |
| CH₃–CH₂–OH | etanol | álcool etílico |
| CH₃–CH(OH)–CH₃ | propan-2-ol | álcool isopropílico |
| H–CHO | metanal | formaldeído (formol) |
| CH₃–CH₂–CHO | propanal | |
| CH₃–CO–CH₃ | propanona | acetona |
| CH₃–CO–CH₂–CH₃ | butanona (butan-2-ona) | |
| CH₃–COOH | ácido etanoico | ácido acético |
| CH₃–CH₂–CH₂–COOH | ácido butanoico | ácido butírico |
| CH₃–NH₂ | metanamina | metilamina |
| CH₃–CO–NH₂ | etanamida | acetamida |
| HO–CH₂–CH₂–OH | etano-1,2-diol | etilenoglicol |

### Numerando corretamente
- **CH₃–CH₂–CH(OH)–CH₃:** numerando pelo lado mais próximo do –OH, ele fica no carbono 2 → **butan-2-ol** (e não butan-3-ol).
- **CH₃–CH₂–CH₂–CH=CH₂:** a dupla fica entre os carbonos 1 e 2 → **pent-1-eno**.
- **CH₃–CH(CH₃)–CH₂–CH₂–CH₃:** cadeia principal de 5 C; metil no carbono 2 → **2-metilpentano**.
- **CH₃–CH₂–CH(CH₃)–CH₂–CH₃:** metil no carbono 3 (dos dois lados dá 3) → **3-metilpentano**.
- Em aldeídos e ácidos carboxílicos, o carbono do grupo funcional é sempre o **1** (por isso não se escreve "propan-1-al").
- Em butanona e propanona, a carbonila só pode estar no carbono 2; o localizador pode ser omitido.

### Contando carbonos pelo nome
"Hept-" = 7 carbonos na cadeia principal; "2,3-dimetilpentano" tem 5 + 2 = **7** carbonos no total (C₇H₁₆). Hexano, 2-metilpentano e 2,2-dimetilbutano têm todos 6 carbonos: são isômeros (C₆H₁₄).

## Manias da banca

- **Prefixo errado:** but- "= 5" (é 4); pent- "= 4" (é 5).
- **Sufixo trocado:** -ol (álcool) × -al (aldeído) × -ona (cetona).
- **Numerar pelo lado errado** (butan-3-ol, pent-4-eno).
- **Infixo trocado:** -en- (dupla) × -in- (tripla).
- **Contar só a cadeia principal** e esquecer as ramificações no total de carbonos.
- **Nome usual × IUPAC:** acetona = propanona; ácido acético = ácido etanoico; acetileno = etino; formol = metanal.
