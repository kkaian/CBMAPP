# QUI-17 — Nomenclatura IUPAC (1 a 8 carbonos)

## Resumo

**Nome = prefixo (nº de C da cadeia principal) + infixo (ligações) + sufixo (função)**

| Prefixo | C | | Infixo | Ligações | | Sufixo | Função |
|---|---|---|---|---|---|---|---|
| met- | 1 | | **-an-** | só simples | | **-o** | hidrocarboneto |
| et- | 2 | | **-en-** | 1 dupla | | **-ol** | álcool |
| prop- | 3 | | **-in-** | 1 tripla | | **-al** | aldeído |
| but- | 4 | | -dien- | 2 duplas | | **-ona** | cetona |
| pent- | 5 | | | | | ácido **…-oico** | ácido carboxílico |
| hex- | 6 | | | | | **-amina** | amina |
| hept- | 7 | | | | | **-amida** | amida |
| oct- | 8 | | | | | | |

**Ramificações (grupos substituintes):** metil (–CH₃), etil (–CH₂CH₃), propil, isopropil (–CH(CH₃)₂).

**Regras básicas:**
1. **Cadeia principal:** a mais longa que contenha o grupo funcional e as insaturações.
2. **Numeração:** começa pela extremidade mais próxima do **grupo funcional**; depois, da **insaturação**; depois, das **ramificações** (menores números).
3. **Localizadores** indicam posições (but-**1**-eno, propan-**2**-ol); **di-, tri-** para grupos repetidos (2,2-dimetil...).
4. Ramificações em **ordem alfabética**, antes do nome da cadeia (3-etil-2-metil...).

## Teoria

### 1. A lógica do nome
O nome IUPAC é montado como uma "palavra de três partes", que dá **quantos carbonos** há na cadeia principal, **que ligações** existem entre eles e **qual é a função**:
\[ \underbrace{\text{prefixo}}_{\text{número de C}} + \underbrace{\text{infixo}}_{\text{ligações}} + \underbrace{\text{sufixo}}_{\text{função}} \]
**Exemplo:** **prop**-**an**-**ol** = 3 carbonos, só ligações simples, álcool.

| Prefixo | Nº de C | Infixo | Ligações entre C | Sufixo | Função |
|---|---|---|---|---|---|
| **met-** | 1 | **-an-** | só simples | **-o** | hidrocarboneto |
| **et-** | 2 | **-en-** | 1 dupla | **-ol** | álcool |
| **prop-** | 3 | **-in-** | 1 tripla | **-al** | aldeído |
| **but-** | 4 | **-dien-** | 2 duplas | **-ona** | cetona |
| **pent-** | 5 | **-di-in-** | 2 triplas | ácido **…-oico** | ácido carboxílico |
| **hex-** | 6 | **-en-in-** | 1 dupla e 1 tripla | **-amina** | amina |
| **hept-** | 7 | | | **-amida** | amida |
| **oct-** | 8 | | | | |

**Bizu dos prefixos:** met 1, et 2, prop 3, but 4 (nomes históricos, é preciso decorar); a partir de 5, o prefixo é o número em grego: pent 5, hex 6, hept 7, oct 8.

### 2. Os grupos substituintes (ramificações)
São "pedaços" da cadeia que saem da cadeia principal. O nome troca o "-ano" do hidrocarboneto por **"-il"**:
| Grupo | Estrutura | Vem de |
|---|---|---|
| **metil** | –CH₃ | metano |
| **etil** | –CH₂–CH₃ | etano |
| **propil** | –CH₂–CH₂–CH₃ (ligado pela ponta) | propano |
| **isopropil** | –CH(CH₃)₂ (ligado pelo carbono do meio) | propano |
| **fenil** | –C₆H₅ | benzeno |

Halogênios como substituintes: **flúor, cloro, bromo, iodo** (ex.: clorometano, CH₃Cl).

### 3. O passo a passo para dar nome
1. **Escolha a cadeia principal:** a **mais longa** que contenha o **grupo funcional** e as **insaturações** (duplas e triplas). Ela pode "dobrar esquinas" no desenho.
2. **Numere** a cadeia a partir da ponta que dá o **menor número**, nesta ordem de prioridade:
   1. ao **grupo funcional**;
   2. às **insaturações**;
   3. às **ramificações** (o conjunto de números mais baixo).
3. **Identifique as ramificações** e suas posições. Use **di-, tri-, tetra-** quando o mesmo grupo se repete, com um número para **cada** um (2,2-dimetil; 2,3,4-trimetil).
4. **Escreva:** ramificações em **ordem alfabética** (ignorando di- e tri-) + nome da cadeia, com os **localizadores** colados por hífen. Números se separam por **vírgula**; números e letras, por **hífen**.

**Exemplo completo:** CH₃–CH(CH₃)–CH₂–CH(CH₂CH₃)–CH₂–CH₃
1. **Cadeia mais longa:** do CH₃ da esquerda até o fim, há dois caminhos depois do C4: seguir para o CH₂–CH₃ da direita ou entrar no CH₂–CH₃ do etil. Os dois têm **6 carbonos**, e a cadeia principal é um hexano. (Contar só a linha reta desenhada e esquecer o etil daria a mesma cadeia aqui, mas em outras estruturas a ramificação "esconde" uma cadeia maior.)
2. **Numeração:** pela esquerda, as ramificações ficam em **2** (metil) e **4** (etil): conjunto (2, 4). Pela direita ficariam em 3 e 5. Vence o menor: (2, 4).
3. Nome: **4-etil-2-metil-hexano** (etil antes de metil, ordem alfabética).

### 5. Erros de numeração mais cobrados
- **CH₃–CH₂–CH(OH)–CH₃:** pela direita, o OH fica no C**2** → **butan-2-ol** (nunca "butan-3-ol").
- **CH₃–CH₂–CH₂–CH=CH₂:** a dupla começa no C**1** (numerando pela direita) → **pent-1-eno** (nunca "pent-4-eno").
- **CH₃–CH(CH₃)–CH₂–CH₂–CH₃:** metil no C2 → **2-metilpentano** (nunca "4-metilpentano").
- **CH₃–CH₂–CH(CH₃)–CH₂–CH₃:** dos dois lados dá 3 → **3-metilpentano**.
- **Grupo funcional antes da ramificação:** CH₃–CH(CH₃)–CH₂–CH₂–OH: numerando a partir do OH, ele fica no C1 e o metil no C3 → **3-metilbutan-1-ol** (e não 2-metilbutan-4-ol).
- **Aldeído e ácido:** o carbono do grupo funcional é **sempre o C1** (não se escreve "propan-1-al"). Ramificações contam a partir dele: CH₃–CH(CH₃)–CHO = **2-metilpropanal**.
- **Propanona e butanona:** a carbonila só pode estar no C2; o localizador pode ser omitido.
- **Metilpropano:** o metil só pode estar no C2 (no C1 aumentaria a cadeia para butano); o "2" pode ser omitido.

### 6. Do nome à estrutura (o caminho inverso)
**Exemplo: 2,3-dimetilpent-2-eno.**
1. "pent" → cadeia de **5 carbonos**: C–C–C–C–C.
2. "-2-en-" → **dupla** entre C2 e C3: C–C=C–C–C.
3. "2,3-dimetil" → um CH₃ no C2 e outro no C3.
4. Complete os H (cada C com 4 ligações): CH₃–C(CH₃)=C(CH₃)–CH₂–CH₃.
5. Fórmula: 5 + 2 = **7 carbonos**; alceno → C₇H₁₄.

### 7. Contando carbonos e reconhecendo isômeros pelo nome
- **Total de carbonos = cadeia principal + ramificações.** 2,3-dimetilpentano: 5 + 2 = **7** C → alcano C₇H₁₆.
- **Hexano**, **2-metilpentano**, **3-metilpentano**, **2,2-dimetilbutano** e **2,3-dimetilbutano**: todos com **6** carbonos e fórmula **C₆H₁₄**, são os 5 **isômeros** do hexano.
- **Propan-1-ol** e **propan-2-ol**: isômeros de **posição**. **Propanal** e **propanona**: isômeros de **função**.

### 9. Bizus finais
- **Prefixo** (nº de C) + **infixo** (an/en/in) + **sufixo** (o/ol/al/ona/oico/amina/amida).
- Cadeia principal: a **mais longa com o grupo funcional e as insaturações**.
- Numerar: **função** > **insaturação** > **ramificação**, sempre pelo **menor número**.
- Ramificações em **ordem alfabética**; di-, tri- não contam na ordem.
- Aldeído e ácido: o grupo é sempre o **C1**.
- Total de C = principal + ramificações.

## Manias da banca

- **Prefixo errado:** but- "= 5" (é 4); pent- "= 4" (é 5).
- **Sufixo trocado:** -ol (álcool) × -al (aldeído) × -ona (cetona).
- **Numerar pelo lado errado** (butan-3-ol, pent-4-eno).
- **Infixo trocado:** -en- (dupla) × -in- (tripla).
- **Contar só a cadeia principal** e esquecer as ramificações no total de carbonos.
- **Nome usual × IUPAC:** acetona = propanona; ácido acético = ácido etanoico; acetileno = etino; formol = metanal.
