# QUI-07 — Número de oxidação

## Resumo

**Nox** = carga real (em íons) ou carga hipotética que o átomo teria se os pares das ligações ficassem com o mais eletronegativo.

**Regras, na ordem de prioridade:**
1. **Substância simples:** Nox = **0** (O₂, H₂, Fe, Na, Cl₂, O₃).
2. **Íon monoatômico:** Nox = **carga** (Na⁺ = +1; Cl⁻ = −1; Fe³⁺ = +3).
3. **Fixos:** grupo 1 (Li, Na, K) = **+1**; grupo 2 (Mg, Ca, Ba) = **+2**; Al = +3; Zn = +2; Ag = +1; **F = −1** sempre.
4. **Hidrogênio:** +1 (exceto em hidretos metálicos, como NaH e CaH₂: **−1**).
5. **Oxigênio:** −2 (exceto peróxidos, como H₂O₂ e Na₂O₂: **−1**; no OF₂: **+2**).
6. **Soma:** zero na espécie neutra; igual à **carga** no íon.

**Atalho de cálculo:** escreva os Nox conhecidos, multiplique pelos índices e iguale a soma a zero (ou à carga).

## Teoria

### 1. O que é o número de oxidação
O **Nox** é uma "contabilidade de elétrons":
- num **íon monoatômico**, é a **carga real** (Na⁺ → +1; S²⁻ → −2);
- numa **ligação covalente**, é a carga que o átomo **teria** se os pares das ligações ficassem inteiros com o átomo **mais eletronegativo**.

**Exemplo:** na água, H—O—H, o oxigênio é mais eletronegativo e "fica" com os dois pares das ligações. Cada H "perde" 1 elétron (+1); o O "ganha" 2 (−2). A soma é \(2(+1) + (-2) = 0\).

Para que serve: identificar quem **perde** e quem **ganha** elétrons numa reação (oxirredução, QUI-10) e acertar o **balanceamento** (QUI-11).

### 2. As regras, em ordem de prioridade
| Nº | Regra | Exemplos |
|---|---|---|
| 1 | **substância simples**: Nox **0** | O₂, O₃, H₂, Cl₂, Fe, Na, S₈ |
| 2 | **íon monoatômico**: Nox = **carga** | Fe³⁺ = +3; Cl⁻ = −1 |
| 3 | **fixos nos compostos**: grupo 1 (Li, Na, K) = **+1**; grupo 2 (Mg, Ca, Ba) = **+2**; **Al = +3**; **Zn = +2**; **Ag = +1**; **F = −1** sempre | — |
| 4 | **hidrogênio**: **+1** com ametais; **−1** nos **hidretos metálicos** (ligado a metal) | HCl (+1); NaH, CaH₂ (−1) |
| 5 | **oxigênio**: **−2**; **−1** nos **peróxidos**; **+2** no OF₂ | H₂O (−2); H₂O₂, Na₂O₂ (−1) |
| 6 | **halogênios**: −1 quando são o elemento mais eletronegativo do composto (cloretos, brometos) | NaCl, HBr |
| 7 | **soma**: **zero** na espécie neutra; igual à **carga** no íon | — |

**Por que a ordem importa:** no **peróxido de hidrogênio** (H₂O₂), se você aplicar "O = −2" primeiro, a soma não fecha. O hidrogênio (+1) tem prioridade: \(2(+1) + 2x = 0\) → \(x = -1\).

### 3. O método de cálculo
1. Escreva o Nox **conhecido** de cada elemento (regras acima).
2. Chame de \(x\) o desconhecido.
3. **Multiplique** cada Nox pelo **índice** (quantidade de átomos).
4. Iguale a soma a **zero** (espécie neutra) ou à **carga** (íon) e resolva.

**Exemplo 1, ácido sulfúrico H₂SO₄:**
\[ 2(+1) + x + 4(-2) = 0 \;\Rightarrow\; 2 + x - 8 = 0 \;\Rightarrow\; x = +6 \]

**Exemplo 2, dicromato K₂Cr₂O₇** (atenção ao índice do Cr):
\[ 2(+1) + 2x + 7(-2) = 0 \;\Rightarrow\; 2x = 12 \;\Rightarrow\; x = +6 \]

**Exemplo 3, íon fosfato PO₄³⁻** (soma = carga):
\[ x + 4(-2) = -3 \;\Rightarrow\; x = +5 \]

### 4. Tabela de exemplos
| Espécie | Conta | Nox |
|---|---|---|
| HNO₃ | +1 + N + 3(−2) = 0 | N = **+5** |
| HNO₂ | +1 + N + 2(−2) = 0 | N = +3 |
| NO₂ / NO / N₂O | | N = +4 / +2 / +1 |
| NH₃ e NH₄⁺ | N + 3(+1) = 0; N + 4(+1) = +1 | N = **−3** |
| SO₂ / SO₃ | | S = **+4** / +6 |
| H₂S | 2(+1) + S = 0 | S = −2 |
| CO₂ / CO / CH₄ | | C = +4 / +2 / −4 |
| CO₃²⁻ | C + 3(−2) = −2 | C = +4 |
| KMnO₄ | +1 + Mn + 4(−2) = 0 | Mn = **+7** |
| MnO₂ | Mn + 2(−2) = 0 | Mn = +4 |
| NaClO (água sanitária) | +1 + Cl − 2 = 0 | Cl = **+1** |
| NaClO₃ / HClO₄ | | Cl = +5 / +7 |
| Fe₂O₃ / FeO | 2Fe = +6; Fe = +2 | Fe = +3 / +2 |
| Fe₃O₄ | 3Fe = +8 | média **+8/3** (mistura de Fe²⁺ e Fe³⁺) |
| H₂O₂ | 2(+1) + 2O = 0 | O = **−1** |
| NaH | +1 + H = 0 | H = **−1** |

**Nox fracionário** (como no Fe₃O₄) é uma **média** entre átomos com Nox diferentes; é possível e aparece em prova.

### 5. Faixas de Nox e o que elas dizem
O Nox mínimo de um ametal é **(grupo − 18)**, e o máximo, em geral, é o **número de elétrons de valência**.
| Elemento | Mínimo | Máximo | Do menor ao maior |
|---|---|---|---|
| **N** | −3 (NH₃) | +5 (HNO₃) | NH₃, N₂ (0), N₂O, NO, HNO₂, NO₂, HNO₃ |
| **S** | −2 (H₂S) | +6 (H₂SO₄) | H₂S, S (0), SO₂, H₂SO₄ |
| **Cl** | −1 (HCl) | +7 (HClO₄) | HCl, Cl₂ (0), HClO, HClO₂, HClO₃, HClO₄ |
| **C** | −4 (CH₄) | +4 (CO₂) | CH₄, C (0), CO, CO₂ |

**Leitura útil:** um elemento no **Nox máximo** só pode **ganhar** elétrons (só pode ser **oxidante**): HNO₃, H₂SO₄ concentrado, KMnO₄, HClO₄. No **mínimo**, só pode **perder** (só **redutor**): NH₃, H₂S, CH₄. Em Nox intermediário, pode ser os dois (SO₂, H₂O₂, Cl₂).

Isso explica por que **nitratos, permanganatos, cloratos e percloratos** são **oxidantes fortes** (alimentam incêndios e explosões) e **metano, gás sulfídrico e amônia** são **combustíveis**.

### 6. Nox em compostos com íons poliatômicos
Separe o composto nos íons que o formam e calcule dentro de cada um.
- **NH₄H₂PO₄** (fosfato monoamônico, do extintor ABC) = NH₄⁺ + H₂PO₄⁻. Em H₂PO₄⁻: \(2(+1) + x + 4(-2) = -1\) → **P = +5**. Em NH₄⁺: **N = −3**.
- **(NH₄)₂SO₄** = 2 NH₄⁺ + SO₄²⁻. Em SO₄²⁻: \(x + 4(-2) = -2\) → **S = +6**.
- **NH₄NO₃** (nitrato de amônio, fertilizante e oxidante perigoso): o **mesmo** elemento com dois Nox: N = **−3** no amônio e **+5** no nitrato. Por isso o composto tem "combustível" e "oxidante" juntos e pode **explodir** (como no porto de Beirute, em 2020).

### 7. Nox no carbono dos compostos orgânicos (noção)
Cada ligação do carbono com **H** soma −1; com **O** (ou N, Cl), +1 por ligação; com outro **C**, 0.
- Metano CH₄: C = −4. Metanol CH₃OH: C = −2. Metanal HCHO: C = 0. Ácido metanoico HCOOH: C = +2. CO₂: C = +4.
- O Nox **sobe** a cada etapa: álcool → aldeído → ácido → CO₂ é uma sequência de **oxidações** (QUI-18), e a **combustão** é a oxidação total.

### 8. Bizus finais
- Simples = **0**; íon = **carga**; soma = 0 (ou a carga).
- H +1 (−1 em hidreto metálico); O −2 (−1 em peróxido); F sempre −1; grupo 1 +1; grupo 2 +2; Al +3.
- **Multiplique pelo índice** (Cr₂, O₇).
- N vai de −3 a +5; S de −2 a +6; Cl de −1 a +7.
- Nox **máximo** → só oxidante (HNO₃, KMnO₄); **mínimo** → só redutor (NH₃, CH₄).
- NH₄NO₃: N −3 e +5 no mesmo composto (perigo).
- Nox subindo = **oxidação**; descendo = **redução**.

## Manias da banca

- **"Nox do H é −1 na maioria dos compostos"** → é +1 (−1 só em hidretos metálicos).
- **"Nox do Cl é sempre −1"** → varia de −1 a +7.
- **Contas erradas por uma unidade** (HNO₃ "+3"; SO₂ "+6").
- **Esquecer o índice** (Cr₂ em K₂Cr₂O₇) ou a carga do íon.
- **"Nox da substância simples é a carga dos átomos"** → é zero.
- **Peróxido com O = −2** → é −1.
